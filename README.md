# 人形机器人动作的物理约束：重定向与扩散生成文献调研

调研问题：人形机器人动作在**重定向**（人 → 人形）和**扩散 / flow 生成**两个层面，已有工作如何满足物理约束（脚不打滑、不穿地 / 不浮空、无自碰撞或场景穿插、接触一致、平衡与动力学可行、关节和力矩限位）。

- 范围：只看人形机器人，不含纯角色动画。
- 规模：59 篇进入表格（重定向 31 篇，生成 28 篇）；读了 69 篇 arXiv 正文的相关段落，另有 2 篇只读摘要。
- 检索：arXiv API 12 条查询；Semantic Scholar 对 14 篇核心论文做前向 / 后向引用追踪，外加关键词检索（8 条中 2 条成功）。截止 2026-11-14。
- 完整表格、归纳、检索记录和局限见 [survey.md](survey.md)。

## 一句话

重定向主要靠优化：常规是加运动学约束，追求可行再加动力学；扩散生成可以在数据、训练损失、采样过程或后训练阶段加约束，最近增长最快的是用跟踪器在仿真里的执行结果来挑样本或微调生成器。

## 重定向

| 做法 | 怎么满足物理约束 | 代表 | 代价 |
|---|---|---|---|
| IK + 软约束（最常用） | 惩罚接触时脚滑、穿地、超限；事后平移修正浮空 / 穿地 | GMR、PhySINK | 每段几秒；不保证力和平衡 |
| 约束优化 | 不穿透、不碰撞、限位、支撑脚不滑写成硬约束 | OmniRetarget、HOI-Retarget | 稍慢；部分情况无解 |
| 动力学轨迹优化 | 变量含力矩、接触力、摩擦 | KDMR、SPARK、Shooting for Contact | 800 帧几十到几百秒；常只对难动作做 |
| 仿真修正 | 策略在仿真中执行参考，用结果替换或修正参考 | OmniTrack、IKMR、DynaRetarget | 要训练策略或大量采样 |

## 扩散 / flow 生成

| 阶段 | 怎么做 | 代表 | 代价 |
|---|---|---|---|
| 训练数据 | 只用清洗过、可执行的动作 | Humanoid-LLA、Movens-Zero | 丢一部分数据 |
| 训练损失 | 足部滑动、接触一致、限位等损失 | WB-UMI、PhysDrift | 微调时可能被破坏 |
| 采样时引导 | 去噪过程或初始噪声上沿物理代价梯度优化 | SafeFlow、HIGenNTO、PhysibleMDM | 推理变慢 |
| 采样后挑选 | 多采样，跟踪器在仿真执行后选最好 | Sample-Simulate-Select、TEXEDO | 候选都不可行时无效 |
| 后训练 | 跟踪器执行结果作为奖励 / 偏好，RL 或 DPO 微调 | RLPF、PhysMoDPO、ViT-H、GenTrack | 结果绑定特定跟踪器 |

## 文件

- `survey.md`：完整调研（表格、归纳、局限、检索记录）。标注【事实】/【作者】/【推断】。
- `data/registry.jsonl`：59 篇的文献注册表（arXiv ID、标题、作者、日期、分类）。
- `scripts/`：检索和抽取脚本，可复现检索。
  - `q.py`：arXiv API 检索。
  - `fetch.py`：下载 arXiv HTML 正文到本地 `txt/`。
  - `ext.py`：按关键词抽取约束、方法、实验、局限相关句子。
  - `ss.py`、`ss2.py`：Semantic Scholar 引用追踪和关键词检索。
  - `filt.py`：引用追踪结果初筛。
- 论文正文和摘要缓存（`txt/`、`cands.json`、`ss_pool.json`）不入库。

## 局限

只读了关键词附近的段落，不是逐篇全文精读；未查 OpenAlex、Google Scholar 和会议官网；Semantic Scholar 关键词检索 6 条因限流失败；最新几篇论文的引用链未收录。详见 `survey.md` 第 6 节。
